# After the V2 beta

## Before inviting the first public cohort

Connect the dedicated Supabase project and private bucket, deploy additive migrations, configure SMTP and authenticated cleanup, appoint manual moderators or vet a moderation provider, and run the hosted checklist in DEPLOYMENT_V2.md. Invite real contributors to a small set of cities. Never substitute seeded posts or counts for participation.

## Next privacy and product improvements

1. Reliable optional on-device face blurring and visible-text/PII review; evaluate failures before advertising protection.
2. Account-scoped encrypted private Moment sync and an explicit optional private copy of a public submission. Keep guest/device history separate and require intentional migration.
3. Durable consent-aware aggregate analytics and internal activation/retention dashboard; define deletion, residency and measurement limitations before adding identifiers. Current session counters are not retention data.
4. Better cross-city diversity selection and pagination within the shared-prompt collection when participation grows. Current city/world feeds paginate; the shared module displays up to six recent matching answers.
5. Trusted environment/event providers with source attribution, observation times and missing-data handling; no generated explanations of unverified conditions.
6. Versioned caption translation preserving the original; reviewed full Hindi/Arabic copy, then languages chosen from real usage.
7. Broader city directory ingestion with a trusted gazetteer and stable aliases. Current launch directory has 66 cities.
8. Stream long private histories/exports, materialize aggregates, expand cleanup throughput, load-test and document measured budgets before broad acquisition.
9. Optional private body-cycle logging with purpose consent and cautious personal comparisons; wearable integrations only after authorized ingestion/retention work.
10. Premium personal entitlements and billing configuration after testing value. World remains free; price does not belong in analytical domain logic.

SOS dispatch, charity custody, open DMs/comments, influencer tools, dating and complex leaderboards remain outside this roadmap's core experiment.
