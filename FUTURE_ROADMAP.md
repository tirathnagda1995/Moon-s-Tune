# Future roadmap

## Before broader consumer acquisition

Validate the configured provider on multilingual and code-switched inputs, including Gujarati and Hinglish; use native-speaker review for emotional language. Test real iOS/Android install, passphrase ergonomics, account recovery and device changes. Add operator-specific legal/contact copy, production SMTP, abuse protections, monitoring, backups and restore drills. Run a hosted two-account release smoke test.

## Next product iteration

Safe export import with schema validation and conflict resolution; explicit guest-to-account migration with re-encryption if required. Local reminders only with permission. Fuller weekly narratives computed from supplied statistics, inspectable missingness, per-pattern feedback, 100-day reports, confirmed long-term replication and more accessible chart views. Vault idle-lock and recovery-key onboarding deserve usability research before changing key management.

## Optional context

Coarse city selection with progressive location/environment permission; timestamped weather providers and true unavailable states. Wearable providers first normalize units, aggregation windows, device metadata, quality and source consent. Treat HealthKit permissions per metric and abide by platform restrictions; do not assume native HealthKit is available to a web PWA. Native companion integrations require a separate project.

Public events need sourced records with geography, severity and uncertain valence. Experimental/traditional variables remain clearly labeled and opt-in, separate from scientific evidence.

## Analytics evolution

Compare candidate hypotheses fairly; pre-specify tests, track multiple comparisons, use block/bootstrap uncertainty for autocorrelated observations, validate temporal lags, hold out future periods and check replication. Preserve personal baselines and independent dimensions. Do not introduce a composite health score without validation.

## Commerce and research

Activate plan capabilities only with a real billing integration, verified webhooks and server authorization. Prices belong in commercial configuration, never canonical data logic. Sell useful software/insights, not raw journal or wearable data. Any research pipeline requires explicit purpose-specific consent, withdrawal, minimum cohorts, suppression, privacy safeguards and legal/research review. There is no population dataset product in V1.
